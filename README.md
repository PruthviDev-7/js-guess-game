# 🎲 Guess The Number Game

A simple number guessing game built with *HTML, CSS, and JavaScript*.  
The game generates a random number and asks the user to guess it until they find the correct answer.

---

## 🚀 Features
- Choose a maximum number range.
- Guess the number until you get it right.
- Hints if your guess is *too small* or *too big*.
- Option to type quit to stop the game.
- Game starts only when you click the *Start Game* button.
- Works in the *browser console* (F12 → Console tab).

---

## 🛠 Tech Stack
- *HTML5*
- *CSS3*
- *JavaScript (Vanilla)*

## 🎮 How to Play
1. Open index.html in your browser.
2. Click the *Start Game* button.
3. Enter a maximum number when prompted.
4. Start guessing the number.
5. Follow the hints (too small / too big) until you guess correctly.
6. Type quit anytime to exit the game.
